# Portable Search MCP 2.1.0

本版本针对扩大测试后暴露的官网导航、新闻覆盖和长尾延迟问题进行了修复。

## 主要变化

- 官网导航查询使用 10 条内部候选、规范化查询和结果重排，最终仍按用户要求返回 1–20 条；
- 中文官网查询在低置信情况下增加政府域名回退；
- 新闻优先使用带发布时间的公开 RSS，DDGS 新闻后端作为回退；
- 新闻继续执行本地日期校验，不以过期或无日期结果补足数量；
- DDGS 单后端超时调整为 3 秒，减少长尾等待；
- RFC 2822 新闻时间现可转换为统一 UTC ISO 时间；
- 基准由 11 个场景、33 次请求扩展为 30 个场景、90 次请求；
- 自动化测试增至 50 项，另有 4 项真实联网测试。

## 最终实测

- 90/90 请求成功；
- 网页和图片 66/66 轮有结果；
- 新闻 24/24 轮有结果，返回新闻的日期完整率为 100%；
- 普通语句官网导航 16/18 轮进入前 5；
- `site:` 限定官网 18/18 轮命中第 1 位；
- URL 有效率和单次结果去重率均为 100%；
- P50 2.537 秒，P95 9.055 秒。

数字来自 2026-08-05 的一次 Windows 公网测试，只代表当时网络出口和公开后端状态，不构成服务等级或固定排序承诺。

## 安装

下载 `portable-search-mcp-v2.1.0.zip`，解压后运行：

```powershell
.\install.ps1
.\verify.ps1 -Live
```
