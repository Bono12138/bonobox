# 安全边界

## 网络边界

模型推理可以继续在本地运行，但搜索词会发送到公开搜索服务，返回结果也来自公网。接入后，整个工作流不能再称为完全离线。

不要在搜索词中放入：

- 客户姓名、手机号、证件号、账号或交易数据；
- 密码、令牌、Cookie、私钥或证书内容；
- 未公开的公司经营数据、模型规则、案件细节或调查结论；
- 能通过组合推断出敏感对象的信息。

## 工具边界

- 只搜索公开网页、新闻和图片，不读取本地文件。
- 不提供任意 URL 抓取，降低服务被用于访问内网地址的风险。
- 只接受预定义参数，拒绝额外参数。
- 搜索词最长 500 个字符，每次最多 20 条结果。
- 上游异常会转换成统一错误，不把原始错误详情返回给模型。
- JSON-RPC 只通过标准输入输出通信，标准输出不写调试日志。

## 发布包边界

发布脚本只收录明确白名单文件，并拒绝：

- 本机用户目录；
- 凭据形式的赋值、令牌样式内容和私钥头；
- 带用户名或口令的 URL；
- 私有数据库写能力材料；
- 白名单外文件、父目录引用和非 UTF-8 文件。

ZIP 内的 `MANIFEST.json` 记录每个文件的 SHA-256。发布页面同时给出整个 ZIP 的 SHA-256，下载后可以核对。

## 使用责任

搜索摘要可能错误、截断或过期。高风险业务结论必须核对原文、发布时间、来源身份和适用范围。本工具不替代公司批准的数据源、权限控制、事实审核或专业判断。
