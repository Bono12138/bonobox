## 行为验收案例

`reality-grounding/references/evaluation-cases.md` 保存六类可观察案例：已有证据、制度与实际做法冲突、无决策价值的问题、权限未知、用户说不清完整流程，以及无需现实调查的确定性任务。

这些案例用于检查 Agent 的实际回答。当前自动测试验证安装和记录结构，没有调用多个外部模型重复生成答案，因此不把案例存在本身写成模型行为已经通过。

## 尚不能由自动测试证明

- 任意 Agent 都能发现并自动触发 Skill；
- 不同模型在所有真实任务中稳定执行调查顺序；
- 用户提供的事实和外部来源一定真实；
- 一次建议经过调查后就一定正确。
