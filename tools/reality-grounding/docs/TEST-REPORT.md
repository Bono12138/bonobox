## 行为验收案例

`reality-grounding/references/evaluation-cases.md` 保存十类现实调查案例。`reality-strategy/references/evaluation-cases.md` 保存九类盲测案例。新增案例专门检查 Agent 能否从混乱的多人事项中找回原始诉求，还原参与方、资源、责任、授权和时间关系，同时避免长问卷和自作主张补充事实。

这些案例用于检查 Agent 的实际回答。当前自动测试验证成对安装、记录结构和关键行为要求是否完整；案例文件存在不等于模型行为已经通过。

## 尚不能由自动测试证明

- 任意 Agent 都能发现并自动触发两个 Skill；
- 不同模型在所有真实任务中稳定执行调查顺序；
- 用户提供的事实和外部来源一定真实；
- 不同 Agent 都能在真实对话中稳定追问、设计非直接路线并持续跟进；这仍需新的独立前向对话验证。
